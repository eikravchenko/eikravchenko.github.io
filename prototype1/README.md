# kravchenko.moscow

Первая версия персонального сайта Евгения Кравченко.

## Структура
- `/` — главная
- `/about/` — обо мне
- `/projects/` — проекты
- `/publications/` — публикации
- `/contacts/` — контакты
- `/css/style.css` — стили
- `/js/main.js` — интерактивность
- `/images/avatar.jpg` — аватар

## Локальный просмотр
Откройте `index.html` через локальный сервер. Например:

`python3 -m http.server 8000`

После этого откройте `http://localhost:8000`.

## Перед публикацией
1. Заменить временную ссылку Telegram на настоящий username.
2. Заменить `hello@kravchenko.moscow` на рабочий адрес, если он будет другим.
3. Добавить реальные публикации.
4. После подключения домена проверить `sitemap.xml`, robots.txt и Open Graph.
5. При необходимости добавить favicon и social preview image.
