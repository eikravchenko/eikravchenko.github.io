# kravchenko.moscow — v2

Персональный сайт Евгения Кравченко.

## Что добавлено в V2
- более выразительный первый экран;
- глубокая тёмно-синяя визуальная система;
- интерактивная карта связей «Бизнес — Пользователь — Продукт — Разработка — Команда»;
- реакция аватара на курсор;
- аккуратные scroll/reveal-анимации;
- светлая/тёмная тема с сохранением выбора;
- адаптивная мобильная версия;
- базовое SEO и sitemap/robots.

## Запуск локально
`python3 -m http.server 8000`

Затем открыть `http://localhost:8000`.

Перед публикацией нужно заменить временные Telegram и email на реальные контакты.
